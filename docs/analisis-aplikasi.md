# Analisis Aplikasi Pertemuan 1

## Aplikasi yang Diamati
Aplikasi Mobile E-Commerce / Pemesanan.

## Target Pengguna
Pengguna perangkat mobile (masyarakat umum / mahasiswa).

## Tiga Fitur Utama
1. Autentikasi dan Pengelolaan Profil Pengguna.
2. Navigasi Katalog dan Pencarian Produk.
3. Riwayat Transaksi dan Pemesanan.

## Usulan Perbaikan
Menambahkan fitur filter pencarian berbasis kategori presisi dan opsi tampilan Dark Mode.
